# Numerical Methods with Julia

This repository contains various Julia examples showcasing different numerical methods and concept with basic Julia tutorials.

## Example of Contents:

- basicproblems.jl: Basic problem examples (Matrix, Factorial)

- cubicspline.jl: Implementation of Cubic Spline interpolation 

- errors.jl:  Error estimation in Julia

- finite_diff.jl:  Finite Difference methods in Julia

- int_examples.jl: Integration problems in Julia

- interpolate.jl: Lagrange interpolation in Julia

- intfunc.jl: Functions for numerical integration namely trapezoidal, Simpson 1/3 and 3/8 rule 


## Usage:

Julia Files: These files can be run in a Julia REPL (read-eval-print loop) or in a Jupyter Notebook.

Pluto Notebooks: These notebooks require Pluto.jl installed. You can open them directly in Pluto.jl and interact with the code and visualizations.
